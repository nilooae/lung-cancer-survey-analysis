# Lung Cancer Survey Analysis

This project analyzes a lung cancer survey dataset using Python, Pandas, Seaborn, and Scikit-learn.

## Project Goals

- Explore the dataset
- Clean column names and duplicate rows
- Analyze target distribution
- Perform exploratory data analysis
- Create simple engineered features
- Prepare the data for machine learning

## Dataset

The dataset contains survey-based features related to lung cancer symptoms and risk factors.

## Current Status

This is an early version of the project.  
Model training and evaluation will be added in the next updates.

## Disclaimer

This project is for educational purposes only and is not intended for medical diagnosis.
